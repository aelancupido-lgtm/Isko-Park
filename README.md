## Isko Park
### Running
  - To run the game, click on IskoPark.jar file in jar_file folder.
  - Alternatively, run `java -jar IskoPark.jar` from jar_file folder in any terminal if Java SE 8.
  - run `java --module-path $FX-PATH --add-modules javafx.controls -jar IskoPark.jar` where `$FX-PATH` is the JavaFX path if Java SE 11 or higher.

### How to play
  - #### Game Objectives
     > This game is a cooperative puzzle multiplayer game composed of 4 players. In this game, the
  players navigate through various levels filled with obstacles and challenges. The primary
  objective is to work together to overcome these obstacles and reach the goal. The goal of this
  game is for the players to acquire all the keys and unlock the door to proceed to the next level with a timeframe of 2 minutes.

  - #### Game Controls
    - Use A, D and SPACE keys to move to the left, right and jump respectively.
  
  - #### Chat
    - To chat, type text in the input box.
    - Use ENTER key to send the message to the chat.
    - Use ESCAPE key to exit the chat box and return to the game.
